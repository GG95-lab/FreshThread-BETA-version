# Reporting a security vulnerability

Do not report vulnerabilities, exploit details, credentials or private data in
public issues. Use this repository's **Security → Report a vulnerability** form.

Private reporting is enabled for this repository:
https://github.com/GG95-lab/FreshThread-BETA-version/security/advisories/new
No response-time or bug-bounty commitment has been established.

An installer hash is an integrity comparison, not independent publisher identity.
FreshThread beta installers initially have no Windows Authenticode signature;
cryptographic updater verification is a separate required release mechanism.
